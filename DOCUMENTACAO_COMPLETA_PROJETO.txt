1. VISÃO GERAL E PROPÓSITO DO APLICATIVO
================================================================================
O FinFlow é uma solução completa de gestão financeira pessoal e empresarial leve,
projetada para operar em tempo real com sincronização entre múltiplos aparelhos
(computadores, tablets e smartphones) através do Firebase Firestore, monetização
nativa via gateway Asaas com PIX instantâneo, cartão de crédito e boleto, leitor
inteligente de extratos bancários com Google Gemini AI e painel de gestão para o
administrador.

Principais Recursos do Sistema:
- **Painel Geral (Dashboard)**: Visão consolidada de Patrimônio Líquido, Saldo Total
  em Contas Bancárias (com Cheque Especial), Fatura do Mês Corrente e Total Investido.
  Possui botões de Suporte WhatsApp oficial e Indicação rápida no WhatsApp.
- **Contas Bancárias & Extrato Unificado**: Gerenciamento de múltiplas contas correntes,
  poupança e carteiras digitais, com histórico de transações, filtros e conciliação.
- **Cartões de Crédito & Compras Parceladas**: Visão por fatura mensal e tabela geral
  de parcelas, atalhos de 1 clique para definir a 1ª fatura e controle de limites.
- **Gestão de Dívidas & Empréstimos**: Tabela detalhada de contratos, credores, taxas,
  número de parcelas e liquidação com débito em conta.
- **Carteira de Investimentos**: Ativos de Renda Fixa, Ações, FIIs, Fundos e Criptoativos.
- **Contas a Pagar & Receber (Agenda Financeira)**: Lançamentos futuros com avisos
  automáticos diários de contas a vencer em até 3 dias.
- **Leitor Inteligente com IA Gemini**: Extração de lançamentos a partir de texto colado
  ou arquivos PDF/imagem em base64.
- **Gateway Asaas e Planos**:
  - Plano Grátis (até 2 contas, até 2 cartões e até 30 transações/mês).
  - FinFlow PRO (contas, cartões, extratos e IA ilimitados).
  - Enterprise BPO (multi-empresas e escritórios contábeis).
- **Painel Administrativo de Assinantes**:
  - Métricas: Total de Usuários, Assinantes PRO, MRR e Taxa de Conversão.
  - Tabela com busca, alteração manual de planos, edição de telefone e WhatsApp direto.
- **Ambiente de Teste Prático de Checkout**: Validação de PIX e travas com 1 clique.

2. STACK TECNOLÓGICA E BIBLIOTECAS
================================================================================
Frontend:
- React 18+ com TypeScript
- Vite como Bundler e Dev Server
- Tailwind CSS com tema dinâmico escuro/claro
- Lucide React (ícones vetoriais)
- Recharts (gráficos interativos)
- jsPDF, jsPDF-AutoTable e XLSX (relatórios executivos)

Backend & Serverless:
- Express e Node.js em server.ts (dev/local e fullstack)
- Vercel Serverless Functions (/api/asaas/*, /api/parse-statement, /api/health)
- @google/genai (Google GenAI TypeScript SDK com Gemini 2.5 Flash)
- Asaas API V3 (PIX dinâmico, Cartão de Crédito e Boleto)

Banco de Dados & Autenticação:
- Firebase Firestore (NoSQL em nuvem com sincronização onSnapshot em tempo real)
- Firebase Authentication (Google OAuth e Email/Senha com RBAC Admin/User)

4. ARQUITETURA BACKEND E API REST / SERVERLESS
================================================================================
Endpoints disponíveis tanto em server.ts (local) quanto em /api/* (Vercel):

1. POST /api/parse-statement
   - Recebe texto puro de extrato bancário ou arquivo base64 (PDF/imagem).
   - Envia ao modelo Gemini 2.5 Flash via SDK @google/genai com prompt especializado.
   - Retorna lista de transações normalizadas (data, descrição, valor, categoria, tipo).

2. POST /api/asaas/create-checkout
   - Recebe userId, userEmail, userName, userCpfCnpj, userPhone, planId, billingType.
   - Cria ou reutiliza o cliente no Asaas (GET /customers?email=...).
   - Cria a cobrança no Asaas (POST /payments).
   - Se PIX: obtém o QR Code dinâmico e código Copia e Cola (GET /payments/{id}/pixQrCode).
   - Retorna paymentId, customerId, invoiceUrl, pixQrCode.

3. GET /api/asaas/check-status/:paymentId
   - Consulta o status de compensação da fatura diretamente no Asaas.
   - Retorna isPaid, status, value, billingType.

4. POST /api/asaas/webhook
   - Recebe notificações de eventos assíncronos do Asaas.
   - Autentica a requisição validando o cabeçalho "asaas-access-token" contra a
     variável ASAAS_WEBHOOK_TOKEN.
   - Trata eventos PAYMENT_CONFIRMED, PAYMENT_RECEIVED e PAYMENT_OVERDUE.

5. GET /api/health
   - Retorna status do servidor, geminiConfigured e asaasConfigured.

5. ARQUITETURA DE DADOS NA NUVEM (FIRESTORE)
================================================================================
Coleções estruturadas:
- users/{userId}: Perfil do usuário (email, displayName, phone, role, subscriptionPlan,
  subscriptionStatus, isPro, updatedAt).
- users/{userId}/subscriptions/current: Dados da assinatura no Asaas.
- users/{userId}/accounts/{accountId}: Contas bancárias.
- users/{userId}/bankTransactions/{txId}: Lançamentos bancários.
- users/{userId}/cards/{cardId}: Cartões de crédito.
- users/{userId}/cardTransactions/{txId}: Lançamentos e parcelas de cartão.
- users/{userId}/futurePayments/{pmtId}: Contas a pagar e receber.
- users/{userId}/investments/{invId}: Ativos de investimento.
- users/{userId}/debts/{debtId}: Empréstimos e financiamentos.
- system/admin_support: { phone: "5511932058703", updatedAt: ... }
- system/asaas_config: Configurações do gateway salvas pelo admin.

Regras de Segurança (firestore.rules):
- Usuários normais só acessam seu próprio nó (isOwner(userId)).
- Usuários administradores (reconhecidos por isAdmin()) possuem permissão para listar
  e atualizar usuários na coleção /users.

6. GATEWAY DE PAGAMENTOS OFICIAL ASAAS
================================================================================
Variáveis Oficiais Configuradas:
- ASAAS_API_KEY: Chave de Produção oficial iniciada com $aact_prod_...
- ASAAS_ENV: "production"
- ASAAS_WEBHOOK_TOKEN: Token de autenticação seguro do Webhook.
- Validação automática: A API identifica o prefixo "_prod_" e conecta diretamente a
  https://api.asaas.com/v3.

Fluxos de Pagamento:
- PIX: QR Code em formato SVG nítido na tela e botão Copiar Código Copia e Cola.
- Cartão de Crédito: Validação de número, titular, validade e CVV.
- Boleto Bancário: Emissão com código de barras digitável e PDF oficial do Asaas.

8. REGRAS DE NEGÓCIO E FEATURE GATING
================================================================================
Plano Grátis:
- Limite de até 2 contas bancárias.
- Limite de até 2 cartões de crédito.
- Limite de até 30 transações por mês.
- Ao tentar cadastrar a 3ª conta ou 3º cartão, o modal UpgradePromptModal é disparado.

Plano FinFlow PRO (R$ 39,90/mês ou R$ 349,90/ano):
- Contas e cartões ilimitados.
- Extratos e transações ilimitados.
- Leitor Inteligente com IA Gemini sem restrições.
- Exportação em PDF Executivo e Excel.

10. GUIA DE DEPLOY E EXECUÇÃO
================================================================================
Execução Local:
$ npm install
$ npm run dev     # Servidor Express + Vite na porta 3000

Compilação e Verificação:
$ npm run build   # Compila o frontend para a pasta dist
$ npm run lint    # Valida tipos TypeScript sem erros (tsc --noEmit)

Deploy na Vercel:
1. Conecte o repositório GitHub na Vercel.
2. Adicione as variáveis de ambiente:
   - GEMINI_API_KEY
   - ASAAS_API_KEY
   - ASAAS_ENV
   - ASAAS_WEBHOOK_TOKEN
   - APP_URL
3. Configure o webhook no painel do Asaas:
   URL: https://seu-app.vercel.app/api/asaas/webhook
   Token: O mesmo valor de ASAAS_WEBHOOK_TOKEN.
